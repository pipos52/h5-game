# H5 Game Project
A simple H5 game that can be packaged into APK using GitHub Actions

## 🎮 Project Structure
```
h5-game/
├── .github/
│   └── workflows/
│       └── build.yml          # GitHub Actions workflow
├── android/                   # Android project (generated by Capacitor)
├── src/
│   ├── index.html            # Main HTML file
│   ├── css/
│   │   └── style.css         # Styles
│   └── js/
│       ├── main.js           # Main game logic
│       └── game.js           # Game implementation
├── package.json              # Node.js dependencies
├── capacitor.config.json     # Capacitor configuration
├── README.md                 # Project documentation
└── .gitignore               # Git ignore rules
```

## 🚀 Quick Start

### Prerequisites
- Node.js >= 16
- npm or yarn

### Installation
```bash
npm install
npx cap add android
```

### Development
```bash
npm run dev
```

### Build APK
Push to GitHub and let GitHub Actions do the magic! ✨
